Setup and privacy

Use Chrome or Edge in a separate window. Choose the Minecraft window, then drag a tight rectangle around the complete XYZ: X / Y / Z or Block: X Y Z line, including minus signs. Prefer XYZ. Keep coordinates visible while playing. Re-select the row after resizing Minecraft, changing its GUI scale, or changing the debug layout.

On macOS, your browser may need System Settings > Privacy & Security > Screen & System Audio Recording access. If the server hides coordinates, this program cannot recover them.

Screen pixels and coordinates stay in this browser. No Minecraft files, memory, mods, packets, or input are accessed. The local server only fetches the public Donut Auction map. Nothing is sent to Minecraft. External tools still need to follow the server's rules; zero ban risk cannot be promised.
